تحدي الثقافة على البيسي (Windows)

1) فك الملف ZIP فشي دوسي (مثلاً على البيرو Desktop).
2) دبل كليك على «تشغيل-تحدي-الثقافة.bat» ← كتحل اللعبة فنافذة طويلة بحال التيليفون (Chrome ولا Edge).
   (إلا ما خدمش: حل web\index.html بـ Chrome مباشرة.)
3) البث المباشر ← لوحة التحكم ← المصدر «TikTok عبر خادمي» ← اكتب:
   - حسابك على TikTok
   - رابط الخادم ديال Render
   - الرمز السري ACCESS_TOKEN
   (هادشي كيتسجل فالبيسي، كتكتبو مرة وحدة فقط.)
4) طلق اللايف فـ TikTok LIVE Studio (ولا OBS) ← زيد مصدر «Window capture / التقاط النافذة» واختار نافذة اللعبة ← خلي الشاشة عمودية 9:16.
5) رجع للعبة وورك «ابدأ جلسة TikTok LIVE». أول ربط ممكن ياخد دقيقة (Render كيفيق).

أزرار الكلافيي أثناء اللايف (بلا ما يشوفو الناس اللوحة):
   Esc         : لوحة التحكم ⇄ شاشة اللعبة
   → ولا N     : التالي / إنهاء الوقت
   Espace ولا P: استراحة / متابعة
   F           : الشاشة الكاملة

الصوت: فـ LIVE Studio زيد «صوت التطبيق / Application audio» ولا خلي صوت البيسي شاعل باش تسمع الموسيقى والمؤثرات.
