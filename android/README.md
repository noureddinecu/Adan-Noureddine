# تطبيق Android — LIVE QUIZ GAME

تطبيق أصلي خفيف (Java + WebView) يفتح **لوحة التحكم** و**شاشة اللعبة** لخادم LIVE QUIZ GAME.

## ما يقدمه التطبيق

- شاشة رئيسية لإدخال رابط الخادم وفحص الاتصال.
- يبقي الشاشة مضاءة أثناء البث.
- وضع ملء الشاشة لشاشة اللعبة.
- تشغيل الأصوات تلقائياً بدون لمسة إضافية.
- رفع الصور والأصوات من الهاتف.
- حفظ ملفات التصدير في مجلد التنزيلات (Download).
- تذكّر تسجيل الدخول.

**الخادم لا يعمل داخل التطبيق.** احتساب الأجوبة واستقبال تعليقات TikTok يتمان في خادم اللعبة (Node.js)، ويمكن أن يكون:

- على الإنترنت (Render، Railway…).
- على نفس الهاتف عبر Termux.
- على جهاز آخر في نفس الشبكة.

## البناء

يُبنى ملف APK تلقائياً عبر GitHub Actions (`.github/workflows/android.yml`) عند كل تعديل في مجلد `android/`، ويُنشر في **Releases**.

البناء محلياً يتطلب Android SDK:

```bash
cd android && gradle assembleRelease
```

## التوقيع

- الملف `app/release.jks` مفتاح توقيع مخصص للتثبيت المباشر. كلمة مروره موجودة في `gradle.properties`.
- يسمح هذا المفتاح بتثبيت التحديثات فوق النسخة السابقة دون حذفها.
- لأنه موجود في المستودع، يستطيع أي شخص يملك صلاحية الوصول للمستودع توقيع نسخة باسم التطبيق.
- لاستعمال مفتاح خاص بك:
  1. أنشئ مفتاحاً جديداً بـ `keytool`.
  2. ضعه مكان `app/release.jks`.
  3. أضف أسرار المستودع `LQG_STORE_PASSWORD` و`LQG_KEY_PASSWORD`.
- النسخ الموقعة بمفتاح مختلف لا تُثبَّت فوق القديمة: احذف القديمة أولاً.
