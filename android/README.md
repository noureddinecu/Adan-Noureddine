# تطبيق Android — LIVE QUIZ GAME

تطبيق أصلي (Java + WebView + Node.js مدمج) يشغّل **خادم اللعبة داخل الهاتف نفسه**، بدون كمبيوتر أو Termux.

## كيف يعمل

- **Node.js مدمج:** يستعمل [nodejs-mobile](https://github.com/nodejs-mobile/nodejs-mobile) بإصدار Node 18، ويُشغَّل عبر مشغّل JNI (`app/src/main/cpp`).
- **خدمة أمامية** (`NodeService`) مع إشعار دائم وقفل للمعالج والواي فاي. بفضلها يستمر الخادم في استقبال تعليقات TikTok حتى عند الانتقال إلى تطبيق TikTok.
- **حزمة الخادم** يبنيها `npm run build:mobile`:
  - الخادم مجمّع في ملف واحد عبر esbuild.
  - الواجهة المبنية وملفات الأسئلة.
  - `sql.js` (قاعدة SQLite بتقنية WebAssembly).
  - مكتبة `tiktok-live-connector` الإصدار 1، لأن الإصدار 2 يتطلب Node 20.
  - كل ذلك يُضغط في `assets/nodejs-project.zip`، ويُفك مرة واحدة لكل إصدار مثبَّت.
- **البيانات** (اللاعبون والنقاط والسجل وأسئلتك) محفوظة في تخزين التطبيق وتبقى بعد التحديث. **تُحذف إذا حذفت التطبيق.**
- **الوصول من أجهزة أخرى:** الخادم يستمع على المنفذ 3000، فيمكن فتح شاشة البث من جهاز آخر على نفس الواي فاي (OBS، جهاز لوحي…).
- **وضع «خادم خارجي»** ما يزال متاحاً للاتصال بخادم على الإنترنت أو على جهاز آخر.
- **المعالج المدعوم:** ARM 64-bit فقط (arm64-v8a).

## البناء

يُبنى تلقائياً عبر GitHub Actions (`.github/workflows/android.yml`)، ويُنشر الملف في **Releases**. الخطوات:

1. بناء الواجهة وحزمة الخادم.
2. تحميل nodejs-mobile.
3. بناء المشغّل الأصلي.
4. توقيع ملف APK.

## التوقيع

- الملف `app/release.jks` مفتاح توقيع مخصص للتثبيت المباشر، وكلمة مروره في `gradle.properties`.
- يسمح بتثبيت التحديثات فوق النسخة السابقة دون حذفها.
- لأنه موجود في المستودع، يستطيع أي شخص يصل إلى المستودع توقيع نسخة باسم التطبيق.
- لاستعمال مفتاح خاص بك: ضع مفتاحك مكانه، وأضف أسرار المستودع `LQG_STORE_PASSWORD` و`LQG_KEY_PASSWORD`.
